# TP-DSW-Frontend (React + TypeScript + Vite)

## Guía de Inicio Rápido

### Requisitos

- Git para clonar el repositorio.
- Node.js 24.14.0 y npm.
- Tener el backend en ejecución en `http://localhost:3000`. Antes de continuar, completá las instrucciones del [README del backend](https://github.com/SantiagoPacenza/TP-DSW-Backend#readme).

Dejá el backend ejecutándose en su terminal y abrí una segunda terminal para los comandos de esta guía.

### 1. Clonar el repositorio e instalar dependencias

```bash
git clone https://github.com/german-a-rodriguez/TP-DSW-Frontend.git
cd TP-DSW-Frontend
npm install
```

### 2. Iniciar el Servidor

- Desde la carpeta `TP-DSW-Frontend`, iniciá el servidor con el comando:

```bash
npm run dev
```

- Vite mostrará en la terminal una dirección junto a `Local:`. Abrí http://localhost:5173 en tu navegador o la dirección que indique la terminal si ese puerto está ocupado.
- Mantené abiertas ambas terminales mientras uses la aplicación.
- Para detener cada servidor, presioná `Ctrl+C` en su terminal.

### Otros scripts disponibles

- `npm run build`: comprueba los tipos y genera los archivos compilados en `dist`.
- `npm run preview`: permite visualizar localmente la compilación. Primero ejecutá `npm run build` y luego abrí la dirección que muestre la terminal. El backend debe seguir en ejecución.
- `npm run lint`: ejecuta las comprobaciones de estilo y calidad del código.
