# TP-DSW-Frontend (React + TypeScript + Vite)

## Guía de Inicio Rápido

### 1. Clonar el repositorio e instalar dependencias

```bash
git clone https://github.com/german-a-rodriguez/TP-DSW-Frontend.git
cd TP-DSW-Frontend
npm install
```

### 2. Iniciar el Servidor

- Una vez configurado todo, levantar el servidor con el comando:

```bash
npm run start:dev
```

- Si está todo bien, en la terminal deberias ver: Servidor escuchando de manera local en http://localhost:5173
- Por ultimo copiá y pega el siguiente link en tu navegador: http://localhost:5173 . Deberías ver el mensaje "Hello, React!"
